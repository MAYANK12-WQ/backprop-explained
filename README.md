# 🧠 Zero-to-Hired: Backprop From Scratch

An **interactive, Colab-ready** notebook that builds a tiny autograd engine (like micrograd) 
from scratch, spells out **backpropagation step by step**, and makes gradients visible.  

🚀 Designed as a teaching + portfolio project to **demystify backprop** and showcase engineering clarity.

---

## 📌 Highlights
- Minimal autograd engine (`Value` class) with `+ - * / ** tanh relu exp`
- Topological backpropagation (no hidden magic)
- Graphviz visualization of forward & backward graphs
- Tiny MLP trained end-to-end
- **Playground mode** with sliders → see gradients update live
- Tested & validated with sanity checks
